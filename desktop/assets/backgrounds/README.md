# SkyCast Desktop Background Photos Directory

Place high-resolution sky/weather wallpaper images here (JPG or PNG format, ~1920x1080 recommended).
If any file is missing, SkyCast automatically falls back to an atmospheric procedural gradient.

### Supported File Names:
1. `clear.jpg` (or `clear.png`) — Daytime clear blue sky with golden sunlight
2. `partly_cloudy.jpg` — Sunny sky with fluffy white cumulus clouds
3. `overcast.jpg` — Gray/slate overcast cloud ceiling
4. `fog.jpg` — Misty or foggy horizon
5. `rain.jpg` — Daytime rain / wet atmospheric sky
6. `snow.jpg` — Winter snow landscape or falling snow sky
7. `thunderstorm.jpg` — Dark dramatic thunderstorm clouds
8. `clear_night.jpg` — Clear starry night sky with moon/milky way
9. `rain_night.jpg` — Dark rainy night with city lights or reflections

At runtime, SkyCast automatically applies a dynamic color tint based on the local time phase:
- **Dawn**: Soft pink/coral tint (45 min around sunrise)
- **Day**: Natural balanced lighting
- **Evening / Golden Hour**: Warm amber/orange glow (1 hour before sunset to 30 min after)
- **Dusk**: Deep violet/purple twilight (after sunset until dark)
- **Night**: Deep navy/midnight atmospheric overlay
- **Frost Tint**: Cool crisp blue-white frost overlay for clear cold days (< 5°C)
